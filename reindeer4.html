Electrical Design 


  
   
This was the first PCB that I've had manufactured. It is a simple board that allows up to 12 servos to be driven from an esp32.
I designed this to be able to use Bottango to drive the servos from a script on the esp32. Bottango is an animation 
software that generates interpolated servo positions between keyframes, and can be exported to a looping animation. 

We used 2-3 boards per reindeer, each running only a couple of body parts. This was for redundancy, if one board or effector failed, 
other parts of the reindeer could still run. Each board has its own switch on the back of the body so that the client can switch
elements off if they want (for example,turn the eyes off if something looks weird, but the red nose will continue to glow).
